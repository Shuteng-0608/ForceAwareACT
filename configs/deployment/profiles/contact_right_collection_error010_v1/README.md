- 首动作误差：七关节均0.1rad。
- 后续待发送目标以及上一已提交目标相对实际反馈误差：七关节均0.1rad。
- 后续相邻已提交目标单步跳变仍为七关节0.03rad。首动作有独立误差门槛，不受此后续单步检查。
- 右臂刚度 [12,12,12,10,9,9,9] N·m/deg；阻尼 [0.3,0.3,0.3,0.2,0.2,0.2,0.2]。

- 原配置保留；必须使用 --controller-profile 显式选择本目录。
- 放宽门槛不是启动平滑修复：现有直接首目标发送及停止后保留最后目标的行为不变。
- 首动作允许偏差0.1rad约5.73°；建议第一次仅人工运行3秒。执行时必须重新确认静止、无接触和无外力，完成本次软件校零。

- 运行报告保存所选profile、SHA256、完整阈值和实际控制器反馈；保留变更记录，便于比较。
